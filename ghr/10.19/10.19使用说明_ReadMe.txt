 10.19  液晶屏彩色显示测试实验  ——  使用说明
====================================================================

平台：鹿小班 STM32F407ZGT6 核心板（LXB407ZG-P1）
屏幕：1.8 寸 / 1.77 寸 ST7735S  SPI 串口屏（128 x 160，14PIN 或 8PIN 均可）
工程：以 10.15 工程（LED 闪烁 + 毫秒延时）为基础，加入厂家 LCD 驱动

二、接线（接核心板板载的 TFT 显示屏接口 P2，直接插屏）
--------------------------------------------------------------------
  核心板边上有 1 只 8 针排针，丝印“TFT显示屏接口 P2”，引脚定义：

  P2 引脚   单片机      液晶屏引脚     说明
  ------------------------------------------------------------------
  1         3.3V       VCC           电源正，千万不要接 5V
  2         GND        GND           电源地
  3         PB15       SDA / MOSI    SPI 数据（单片机 -> 屏）
  4         PB13       SCL / SCK     SPI 时钟
  5         PB12       CS            片选，低电平有效
  6         PB14       RES / RST     复位，低电平有效
  7         PC5        DC / RS       命令 / 数据选择
  8         PB1        BLK / LEDA    背光，高电平点亮

  * 本工程 lcd_init.h 已按上表把引脚定义好，并把 LCD_HAS_RES 设为 1，
    上电后由 PB14 先给屏一个 100ms 的低电平复位脉冲，再初始化。
  * 如果手里的屏没有 RES 脚（自带复位电路的 1.8 寸带字库屏），把
    lcd_init.h 里的 #define LCD_HAS_RES 改成 0，PB14 空着即可。
  * 液晶屏是 3.3V 器件，P2 的第 1 脚就是 3.3V，不要接到 5V 上。
  * 1.77 寸 14PIN 屏的引脚顺序大多是 GND/VCC 在两端、中间是信号线，
    插之前一定核对一下屏背面的丝印，别把电源插反。

三、编译和下载
--------------------------------------------------------------------
  1. 用 Keil uVision5 打开：Project\STM32F407.uvprojx
     （和 10.15 完全一样的工程结构，打开即可）

     生成的固件：Project\Objects\STM32F407.hex

四、程序显示的内容（main.c，while(1) 里循环）
--------------------------------------------------------------------
  1. Test_SolidColor    全屏纯色，5 秒一张：白、黑、红、绿、蓝、黄、青、品红、
                        橙、粉、紫、金、天蓝、青、藏青、橄榄、银、深灰、深绿、深红……
  2. Test_ColorBars     8 色彩条：先竖条 1.5 秒，再横条 1.5 秒
  3. Test_GrayScale     16 级灰度条 + 连续灰度渐变（看灰阶、伽马是否正常）
  4. Test_ColorGradient RGB 三原色渐变（红/绿/蓝各占三分之一屏，亮度 0->255）
  5. Test_Rainbow       彩虹色带（色相从左到右 0->360 度）
  6. Test_ColorGrid     4 x 4 十六色方块，白色线分隔

  每换一个画面，LED1（PC13）翻转一次 —— LED 闪说明程序在跑，
  如果 LED 在闪但屏是黑的，问题一定出在接线或背光/复位上。


五、想改东西时改哪里
--------------------------------------------------------------------
  * 改颜色顺序 / 增删颜色：main.c 里的 ColorTab[]、BarTab[] 和
    文件顶部 #define 的扩展颜色（RGB565 格式，例如 0xF800 是红色）
  * 改引脚（改成非 P2 的引脚时）：lcd_init.h 里的 LCD_MOSI_xxx / LCD_SCLK_xxx / LCD_CS_xxx /
    LCD_DC_xxx / LCD_BLK_xxx / LCD_RES_xxx 宏，同时要改 lcd_init.c 中
    LCD_GPIO_Init() 里使能的 GPIO 时钟和引脚列表（注意 PC5 属于 GPIOC）
  * 改横屏/竖屏：lcd_init.h 的 USE_HORIZONTAL（0/1 竖屏，2/3 横屏）
  * 每个画面停留时间：main.c 里的 Delay_ms(500/1500/2000...)
  * 想换显示的照片：见下面第七节


六、常见问题
--------------------------------------------------------------------
  1. 白屏 / 全黑 / 只亮背光不显示
     a. 先量 VCC 是不是 3.3V，BLK 是不是高电平（可以把 BLK 直接接 3.3V 试）
     b. 屏有 RES 脚却没接 -> 本工程 RES 已固定接 PB14（P2-6），检查这一针是否接触良好
     c. 检查 SCL(PB13)/SDA(PB15)/CS(PB12)/DC(PC5)/RES(PB14) 有没有接反或插错针
     d. 杜邦线尽量短（PB13/PB15 已开内部上拉）；能直插 P2 排针最好
  2. 花屏 / 雪花 / 颜色错乱
     a. 降低速度：把 LCD_Writ_Bus() 里的 SCK 加一点空操作（__NOP()），
        软件 SPI 跑得太快时个别模块会误码
     b. 颜色整体偏红/偏蓝：说明屏是 BGR 排列，把 lcd_init.c 里 0x36 寄存器
        的值与 0x08 异或（例如 0xC0 改成 0xC8）
  3. 图像上下颠倒 / 左右镜像
     a. 改 USE_HORIZONTAL 的值（0/1/2/3 四个方向都试一下）
     b. 或者直接改 0x36 寄存器的 MX/MY 位（0x08 是 BGR，0x40 是 MX，0x80 是 MY）
  4. 只有上半屏或下半屏有图像
     a. 屏幕可能是 128x160 的 ST7735S，有的批次需要设置 GRAM 偏移
        （0x2A 列偏移、0x2B 行偏移），本工程按厂家例程不加偏移
  5. 编译报错找不到 lcd.h / lcd_init.h
     -> Options for Target -> C/C++ -> Include Paths 里要有 ..\Drive\Include
        （本工程已经加好，从 10.15 复制过来时不会丢）

七、显示自己的图片（10.19 新加）
--------------------------------------------------------------------
  1. 工程里已经带了一张示例图片（日落风景），满屏 128x160：
       图片数据：MY\pic.h
       生成脚本：tools\make_demo_pic.py
       预览图  ：tools\demo_preview.png（电脑上直接双击就能看）
     不满意可以重新生成一遍：python tools\make_demo_pic.py

  2. 换成自己的照片（电脑要先装好 Python 和 Pillow：pip install pillow）：
       在 10.19 目录下执行：
         python tools\img2c.py 你的图片.jpg MY\pic.h
     * 图片会自动“等比缩放 + 居中裁剪”到 128x160，不会拉伸变形；
     * 生成的 pic.h 里是一个 const unsigned char gImage_pic[40960]，
       放在 Flash 里，不占 RAM（F407ZG 有 1MB Flash，很富裕）；
     * 如果以后改成横屏（USE_HORIZONTAL 2 或 3），生成时就加参数：
         python tools\img2c.py 你的图片.jpg MY\pic.h --w 160 --h 128

  3. 显示代码在 main.c 的 Test_Picture()：
         LCD_ShowPicture(0, 0, LCD_W, LCD_H, gImage_pic);
     其中 (0,0) 是左上角坐标，LCD_W/LCD_H 是要显示的宽度和高度。

  4. 说明：
     * 图片是 RGB565（16 位色），每像素 2 字节，高字节在前，和
       LCD_ShowPicture() 里 LCD_WR_DATA8(pic[k*2]); LCD_WR_DATA8(pic[k*2+1]);
       的写法对应，所以不要手工改 pic.h 的字节顺序；
     * 一张 128x160 的图要 40KB Flash，F407 放几十张都没问题；
     * 图片如果整体偏红/偏蓝，和彩条偏色一样处理：屏是 BGR 排列，
       把 lcd_init.c 里 0x36 寄存器的值与 0x08 异或。
