# 03-实验台

> 试过、但**没进主线**的东西放这里。允许脏、允许半成品、允许最终证明"这条路不行"。
> 目的只有一个：**别让实验污染交付包，也别让做过的实验白做。**

## 三条硬规矩

1. **不放大件进 git**：这里的东西基本不进版本控制（`Qwen/` 有 33.7 GB，`.venv`、`downloads/` 都排除）；
2. **`01-交付包` 严禁 import 这里的任何东西**：交付包必须能单独拷走运行。真要用某个结论，把代码搬进 01；
3. **每月看一次体积**：有结论超过 30 天的实验，删数据、留 README。

## 四状态

每个实验目录的 `README.md` 第一行必须标明状态：

| 状态 | 含义 | 到期动作 |
|---|---|---|
| `【进行中】` | 还在试 | 无 |
| `【有结论】` | 结论拿到了，数据留着备查 | 30 天后删数据，只留 README |
| `【已毕业】` | 代码/结论已并入 `01-交付包` | 可以整个删掉，或只留一句话索引 |
| `【已放弃】` | 此路不通 | **只留"为什么不行"**，代码可删 |

## 怎么新开一个实验

```bash
mkdir 03-实验台/我的实验
cp 03-实验台/00-模板/README.md 03-实验台/我的实验/README.md
# 填 README，然后就开始试；有结论后回来改状态
```
