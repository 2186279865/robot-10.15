# 10.17 ST7735S 屏幕测试

基于 `10.15` 的 STM32F407 工程建立的独立测试工程。沿用启动文件、系统时钟、标准外设库、SysTick 毫秒延时和 PC13 LED 驱动；仅运行屏幕测试，不初始化电机、舵机和 USB。原 `10.15` 工程未修改。

## 打开和下载

1. 用 Keil 打开 `Project/STM32F407.uvprojx`，目标名 `STM32F407`，芯片 STM32F407ZGTx。
2. 编译器使用 ARMCC **V5.06 update 6**，执行 Rebuild。
3. Debug 选择 ST-Link Debugger，使用 SWD；Utilities 选择 Use Debug Driver，确认 Flash 算法为 STM32F4xx 1024KB。
4. 下载后复位运行。编译产物为 `Project/Objects/TFT_ST7735_Test.hex`。

已在本机通过 ARMCC 5.06 编译：0 Error(s)、0 Warning(s)。尚未下载到实物验证。

## 接线

以下 P2 编号来自提供的原理图，屏幕编号来自配套封面图背面丝印。以实物的 1 脚标记为准，不能根据照片左右方向判断排针编号。

| 核心板 TFT 接口 | 信号 | 屏幕针脚 |
|---|---|---|
| 1 | PB1 / 背光逻辑控制 | 8 LEDA |
| 2 | PC5 / RESET | 5 RES |
| 3 | PB14 / DC | 6 RS |
| 4 | PB12 / CS | 7 CS |
| 5 | PB13 / SCK | 3 SCK |
| 6 | PB15 / MOSI | 4 SDA |
| 7 | GND | 1 GND |
| 8 | 3V3 | 2 VCC |

开发板接口从左到右实际是：`1 PB1，2 PC5，3 PB14，4 PB12，5 PB13，6 PB15，7 GND，8 3V3`。屏幕接口从左到右是：`1 GND，2 VCC，3 SCK，4 SDA，5 RES，6 RS，7 CS，8 LEDA`。因此不能把两个排针的 1～8 直接对插；必须按上表交叉接线。

屏幕 **8 LEDA、9 LEDK 是背光正负端**。先核实模块的背光限流电路与电流，PB1 仅作为逻辑控制输出，不默认允许直接给 LEDA 供电。若使用低边 N-MOS 驱动：LEDA 经匹配的限流电路接背光电源，LEDK 接漏极，源极接 GND，PB1 经栅极电阻控制栅极并加下拉；模块已有的限流电阻要计入。也可以在确认限流和供电规格后使用固定背光供电，这时 P2 的 PB1 不接。所有供电共地。

屏幕 10～13 为 GT 字库接口，本程序使用 MCU 内置 ASCII 字库，不连接这些脚；14 是 GND，可接共地。

## 运行现象

当前诊断版先让 PC13 LED 快闪三次，再初始化屏幕；初始化过程中 LED 每 150ms 翻转，初始化完成后每 500ms 翻转。屏幕先显示白色约 1.5 秒，然后循环执行：红 → 绿 → 蓝 → 白 → 黑，各保持约 800ms；随后显示 `10.17 TFT TEST`、型号和分辨率、RGB 三色块、四周一像素白色边框，以及绿色进度条。软件 SPI 刷整屏会有可见的扫描过程，属于本测试的正常现象。

Keil 调试时可在 Watch 查看 `g_tft_stage`：1=进入 main；2=启动三闪；3=GPIO 初始化；4=硬件复位；5=发送初始化命令；6=清屏；7=初始化完成；8=测试循环。此变量表示 CPU 执行位置，不表示屏幕已应答。诊断版增加了 0x01 软件复位与 150ms 等待。

背光固定使用 `TFT_BACKLIGHT_ACTIVE_HIGH` 指定的有效电平，不再在运行中交替切换 PB1。初始化期间不主动关闭背光，并补充了 0x13 正常显示模式命令。

## 文件和可调参数

- `MY/main.c`：测试顺序与画面内容。
- `Drive/Source/tft.c`：软件 SPI、复位、绘制矩形和 ASCII 文字。PB14 是 GPIO 输出，不使用 SPI2 MISO。
- `Drive/Source/tft_init.inc`：取自提供的 ST7735 例程的初始化命令序列。原文件中的“1.44/ST7735R”注释与商品资料名称不一致，因此最终兼容性仍以实物显示为准。
- `Drive/Include/tft.h`：分辨率、颜色、偏移、扫描方向和背光有效电平。
- `Drive/Include/tft_font.h`：从提供例程 `Font.h` 提取的 8×16 ASCII 字模。

窗口终点统一为 `起点 + 长度 - 1`，起终点使用同一个偏移，修正了原例程结束坐标额外加 2/1 的写法；绘制接口会裁剪超出屏幕的区域。

## 显示异常时

- 背光不亮：先检查 LEDA/LEDK 的供电与限流、驱动电路和共地。
- 只有白屏：检查 RES、RS/DC、CS、SCL、SDA 接线及排针方向。背光亮不代表初始化成功。
- 红蓝互换：将 `TFT_MADCTL` 从 `0xC0U` 改成 `0xC8U` 后重新编译。
- 边框缺边或整体偏移：检查 `TFT_X_OFFSET`、`TFT_Y_OFFSET`，默认均为 0；根据该块屏幕实际可视区域校准。不要单独增加窗口终点。
- LED 正常切换但无图像：说明主循环在运行，继续检查屏幕连接和初始化兼容性；LED 不是屏幕通信成功的反馈。

新文件使用 UTF-8；从 `10.15` 复制的文件保留原编码。
