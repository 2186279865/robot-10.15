# 无线组网联调：笔记本（视觉端）↔ 香橙派（机器人端）

目标：笔记本开着热点，香橙派连上来，两端在同一网段跑通“视觉帧 → 机器人端”，
不依赖相机、不依赖现场路由器。每一步都有成功判据，卡住时看第 8 节。

## 0. 链路和端口

```
香橙派 ──wlan0──▶ 笔记本热点（192.168.137.0/24，笔记本固定 192.168.137.1）
                     │   TCP 5055：视觉帧，每行一个 JSON（\\n 结尾）
                     │   UDP 5056：视觉端每 0.8s 广播自己 IP+端口（自动发现）
                     ▼
                机器人端 link_robot_example.py ──可选串口 0xAA55 帧──▶ 单片机
```

- 帧格式、`u/v` 坐标含义、串口 CRC 见 `new_eye/link.py` 顶部注释；
- 端口只在笔记本侧监听，香橙派侧是客户端，**不需要在派上开防火墙**。

## 1. 笔记本：确认热点已开

Windows 11：设置 → 网络和 Internet → 移动热点 → 编辑 → 网络频段选 **2.4 GHz**
（很多香橙派只有 2.4G 单频；选 5G 会搜不到），打开“移动热点”。

确认热点网段：

```powershell
ipconfig | findstr "192.168.137"
```

预期看到 `192.168.137.1`（ICS 固定给笔记本这个地址）。没有的话：热点没开成，
先看第 8 节第 1 条。

## 2. 笔记本：放行防火墙（管理员 PowerShell）

```powershell
netsh advfirewall firewall add rule name="new_eye-tcp" dir=in action=allow protocol=TCP localport=5055
netsh advfirewall firewall add rule name="new_eye-udp" dir=in action=allow protocol=UDP localport=5056
```

热点网络会被 Windows 判成“公用”，上面两条默认对所有配置文件生效，够用。

## 3. 笔记本：先自检（不需要香橙派）

```powershell
python new_eye/link_demo.py --selftest
```

成功判据：`自检通过：收到第 1 帧，2 个目标，u/v = [...]`。
这一步只验证本机 TCP + UDP 广播 + JSON 解析没问题；失败先查 5056/5055 是否被
其它程序占用（`netstat -ano | findstr 5055`）。

## 4. 香橙派：连热点并验证

Debian/Ubuntu + NetworkManager（Orange Pi 官方系统一般都有）：

```bash
nmcli device wifi list
nmcli device wifi connect "笔记本热点SSID" password "你设的密码"
ip -4 addr show wlan0 | grep inet          # 期望 192.168.137.x
ping -c 3 192.168.137.1                    # 期望 0% packet loss
sudo iw dev wlan0 set power_save off       # 关省电，否则空闲会卡 200ms+
```

没有 `nmcli` 的镜像：用 `nmtui` 图形界面连，或写 `/etc/wpa_supplicant/wpa_supplicant.conf`
后 `wpa_cli reconfigure`；拿到 192.168.137.x 就说明链路通了。

## 5. 两端跑起来

**笔记本终端 A**（相机/视觉没好时先用假帧）：

```powershell
python new_eye/link_demo.py
```

输出里会打印 `本机 IP：...` 和 `第 1 帧 → 0 个客户端在线`。
看到 `→ 1 个客户端在线` 说明派连上了。用真实视觉时，改成 GUI 顶栏勾
**“网络推送”**（端口 5055，日志里也会列出所有本机 IP）。

**香橙派终端 B**：

```bash
python3 new_eye/link_robot_example.py            # 自动发现（推荐）
# 自动发现失败时才写死：
python3 new_eye/link_robot_example.py 192.168.137.1 5055
```

成功判据：派上每秒打印一行，例如

```
[帧 5] 2 个目标  #1 圆柱黄 u=0.356 v=0.378 | #2 五棱体红 u=0.659 v=0.512  (间隔 1.00s)
```

## 6. 验收清单

- [ ] 派 `ping -c 3 192.168.137.1` 全通
- [ ] 派每秒收到 1 帧，`间隔 1.00s`，目标数正确
- [ ] 笔记本 Ctrl+C 停掉 demo，2 秒内派打印 `[!] 超过 2 秒没有新帧，机器人应停止等待`
- [ ] 重新启动 demo，派几秒内（≤5s，含一次 3s 发现超时 + 1s 重试）自动重连并继续收帧（不用重启脚本）
- [ ] 拔掉笔记本外网/换现场 WiFi 后，只要热点还在，派仍能收到（局域网不依赖外网）

## 7. 接单片机（可选，链路：笔记本 → 派 → 串口）

```bash
pip3 install pyserial            # 只有要转发串口时才需要；没装也能收 TCP 帧
python3 new_eye/link_robot_example.py 192.168.137.1 5055 /dev/ttyUSB0 115200
```

派收到 TCP 帧后原样打包成 `0xAA 0x55 | len(2B 小端) | JSON | crc16(2B 小端)` 写串口，
CRC-16/MODBUS；`pack_uart()/unpack_uart()` 在 `new_eye/link.py`。

## 8. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 热点开关灰/打不开 | 网卡不支持 AP+STA 并发或驱动旧 | 更新无线网卡驱动；用 USB 无线网卡；或改网线直连 |
| 热点开了但派搜不到 SSID | 热点频段 5GHz，派只有 2.4G | 热点设置里改 2.4GHz；手机先搜一下确认热点可见 |
| 派连上但 ping 不通 192.168.137.1 | 防火墙/ICS 问题 | 管理员跑 `Get-Service SharedAccess` 看是否 Running；关掉热点重开；确认第 2 步规则已加 |
| ping 通但 TCP 5055 连不上 | 端口被占用，或规则没生效 | `netstat -ano \| findstr 5055` 看谁占用；确认没有同时开 GUI“网络推送”和 demo |
| 自动发现失败（链路本身通） | UDP 5056 被拦；或笔记本开着 VPN/TUN | 先写死 `192.168.137.1 5055`；`link.py` 已改成每个本机网卡各广播一份，若仍失败可临时退出 VPN |
| 帧间隔抖动大、偶尔卡 1~2s | 2.4G 干扰 / 派无线省电 | 换信道；执行 `iw dev wlan0 set power_save off`；靠热点近一点 |
| 派拿不到 192.168.137.x | ICS 的 DHCP 没起来 | 关闭再打开移动热点；`services.msc` 重启 “Internet Connection Sharing (ICS)” |
| 笔记本日志里的“本机 IP”是 26.x/其它 | 这台开了 VPN（如 Radmin VPN），列表里第一个不是热点 | 以 `192.168.137.1` 为准；派用自动发现时不受影响 |

## 9. 现场加固（可选）

1. **固定 IP 不必须**：`discover()` 每 0.8s 广播，换网段也能自己找到；只有现场
   多播被拦时才写死 `192.168.137.1 5055`。
2. 香橙派端开机自启（systemd 示例，路径按实际改）：

```ini
# /etc/systemd/system/link-robot.service
[Unit]
Description=new_eye TCP link
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/orangepi/robot-competition/new_eye/link_robot_example.py
Restart=always
WorkingDirectory=/home/orangepi/robot-competition/new_eye

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now link-robot
journalctl -u link-robot -f
```

3. 部署到派上最少只需要 `new_eye/link.py` + `new_eye/link_robot_example.py`
   两个文件（纯标准库；pyserial 只影响串口转发）。
4. 换热点 SSID/密码后，派上删掉旧连接再连：`nmcli con delete "<旧SSID>"`。
