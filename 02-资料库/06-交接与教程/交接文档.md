## 二、当前固件在做什么

`ghr/10.15/MY/main.c`：

```
上电：
  1. 串口回环自检（PA2↔PA3 短接则回显），LED 闪 1/2/3 次报告结果
  2. Stepper_StopAll() → Stepper_EnableAll(1) → 等 500ms     （照例36 的顺序）
  3. Gripper_Init()  舵机停到松开位 180°

按 PA0 一次：
  1. 抓夹收紧一步 45°（180 → 135 → 90 → 45 → 0，到 0 停止）
  2. 全部电机（地址 1~4）以速度模式 F6 转 1 秒，然后 FE 停车
  3. 方向每次按键交替（正 / 负）
```

**各模块参数**（要调参改这些宏）：

| 模块 | 头文件 | 关键参数 |
|---|---|---|
| 舵机 | `Drive/Include/servo.h` | PB6 / TIM4_CH1 / 50Hz；500~2500us ↔ 0~270° |
| 抓夹 | `Drive/Include/gripper.h` | `OPEN_DEG=180`、`GRAB_DEG=0`、`STEP_DEG=45`、`STEP_WAIT_MS=200` |
| 按键 | `Drive/Include/key.h` | **PA0 内部下拉、按下读到高**；`DEBOUNCE_MS=20`、`TASK_MS=1` |
| 步进 | `Drive/Include/stepper.h` | PA2 / USART2 / 115200；地址 Z=1 托盘=3 X=4 Y=5；`SPEED_RPM=300`、`ACCEL=128`、`PULSES_PER_REV=3200` |

## 三、⚠️ 这个工程的三个特殊约定（不知道就会踩坑）

### 1. 模块实现放在 `*_inline.h` 里，不是 `.c`

`MY/main.c` 里有这几行，**它们是实现代码，删了会链接报 `Undefined symbol`**：

```c
#include "gripper_inline.h"
#include "key_inline.h"
#include "stepper_inline.h"
```

原因：**Keil 保存工程时会用内存里的旧文件列表覆盖 `.uvprojx`**，导致从外部加进去的 `.c` 不被编译。所以把实现放进头文件，由 `main.c` 编译时带进来，**不需要改工程文件**。

因此 `Drive/Source/gripper.c`、`stepper.c` 是**参考副本，当前不参与编译**。不要把它们加进 Keil 工程——会 `Multiply defined symbol`。

> 已记入 `新手联合开发完整教程.md` 第 6 章"铁律一"。

### 2. 按键是"内部下拉 + 按下为高电平"

```c
key.GPIO_PuPd = GPIO_PuPd_DOWN;   // PA0
```

这是从 **例36**（唯一按键实测好用的工程）照抄的。**之前用"上拉 + 按下为低"绕了很久都读不到**，改成下拉立刻正常。改按键代码时务必保持这个极性。

### 3. 源文件是 GBK / UTF-8 混合编码

- **GBK**：`Drive/Source/delay.c`、`led.c`、`Drive/Include/delay.h`、`led.h`、`MY/stm32f4xx_it.c`
- **UTF-8**：`MY/main.c`、`servo.h`、`gripper*.h`、`key*.h`、`stepper*.h`、`servo.c`、`gripper.c`、`stepper.c`

ARMCC 两种都能编译，**不要为了"统一"批量转码**（会让 diff 整个文件变红）。用 Keil 编辑最安全。

## 六、硬件接线

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| 舵机（抓夹） | **PB6** | TIM4_CH1，50Hz | 500~2500us ↔ 0~270° |
| 按键 | **PA0** | GPIO 输入，**内部下拉** | 按下读到高 |
| 步进电机 | **PA2** | USART2 TX，115200 8N1 | 只发不收，PA3 留空 |
| 板载 LED | **PC13** | GPIO 输出 | 低电平点亮 |
| 调试串口 | PA9 / PA10 | USART1 | 预留 |

**电源**：步进驱动器需独立 **12~48V** 电机电源；舵机需 **4.8~7.4V**；**都必须和 STM32 共地**。

**电机地址**：Z=1、托盘=3、X=4、Y=5（同一条 PA2 总线靠地址区分）。
