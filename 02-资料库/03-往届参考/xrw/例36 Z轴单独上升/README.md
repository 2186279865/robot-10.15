# 例36：PA0按键Z上升20圈再下降20圈

仅控制地址01的Z轴；上电不自动转动：

1. 发送FE停车；
2. 发送F3使能；
3. 等待500ms；
4. 等待PA0按键有效按下，方向01（CCW）发送相对位置FD上升20圈；
5. 等待7秒，再顶部稳定等待500ms；
6. 方向00发送相对位置FD下降20圈，等待7秒；
7. 完成后等待松开再按一次，不自动循环，长按仅触发一次。

不控制X04/Y05，不初始化舵机，不使用视觉。

## 接线

```text
STM32 PA2 / USART2_TX → Z01驱动器RX
STM32 GND            → Z驱动器通讯GND
驱动器TX             → 不接
PA0                  → 板载WK_UP按键（按下高电平，程序内部下拉）
外接按键             → PA0与3.3V之间，不接5V/电机动力电源
```

驱动器动力电源按铭牌单独连接。

## 修改速度与时间

`HARDWARE/EMM/app_config.h`：

```c
#define Z_SPEED_RPM 300U
#define Z_ACCEL 128U
#define Z_PULSES_PER_REV 3200UL
#define Z_TRAVEL_TURNS 20UL
#define Z_POSITION_WAIT_MS 7000UL
#define Z_UP_DIRECTION 1U
```

本版保留低速300RPM、缓启动128，不直接修改驱动电流。
方向01、Z01地址、PA2接线不变；不修改驱动电流、细分或保护设置。
下降FD为`01 FD 00 01 2C 80 00 00 FA 00 00 00 6B`，
上升FD为`01 FD 01 01 2C 80 00 00 FA 00 00 00 6B`。
每段相对位置命令只发一次，不重发、不用时间FE截断正常圈数。
软件中止或发送失败会尝试FE，不释放垂直轴使能。

默认16细分、1.8度电机，每圈3200脉冲，20圈为64000脉冲；
若实物为32细分，必须改`Z_PULSES_PER_REV`为6400，否则圈数不同。
没有位置反馈，7秒是流程完成等待，不保证实物到位，需先实测。
300RPM下20圈理想4秒，缓启动/减速另需时间，暂留7秒余量。
忙期间所有按键丢弃，不排队；故障后锁定，需要排查后复位。
若仍不转，应查额定电流、负载、限位和驱动报警，不应无上限加电流。
