## 4. 架构与数据流（不变的部分）

```
[顶视相机] --JPEG--> 派(camera_agent/pi_agent:5057)
                        │
[笔记本 host GUI] <──────────────────────────┐
   ├─ 视觉页: 取帧 → SAM → 融合 → 规则分类 → latest_targets.json
   ├─ 动作序列: auto_runner 读目标 → 生成四轴脉冲 → 发命令
   └─ 串口桥 5058 → 派 → /dev/ttyACM0 → STM32 → 驱动器
[显示] 派 HDMI 小屏 ← 5059 display_state（或笔记本副屏）
```

**职责划分**：识别与决策在笔记本（SAM 只能在笔记本跑，0.98 fps）；派只做"取图 + 串口透传 + 显示"；STM32 只做"收帧 + 发帧 + 闭环 goto + 角度模式"。

## 5. 精简流程：8 状态（替代原 19 状态）

| 状态 | 动作 | 判据/超时 | 失败去向 |
|---|---|---|---|
| `S1 CAPTURE` | 顶视取 1 帧 + SAM 分割 | 3 s | FAULT |
| `S2 DECIDE` | 选目标（完整度→近通道→面积）+ 分类 + 盒号 + 算 X/Y 目标脉冲 | 2 s | FAULT |
| `S3 TRAY` | `motor_angle 3 <deg>` 到该盒角度 | 3 s | FAULT |
| `S4 OUT` | 通道出门：`Y +Δy` → `Z_LOW→Z_HIGH` | 4 s | FAULT |
| `S5 PICK` | X/Y 闭环对准 → `Z→Z_PICK` → 夹 135° → `Z→Z_HIGH` | 6 s | FAULT |
| `S6 BACK` | X/Y 回 P1 → `Z_HIGH→Z_LOW` → `Y -Δy` | 5 s | FAULT |
| `S7 DROP` | 松爪 180° → 等 0.3 s → 回 150° → 显示 + 计数 | 2 s | FAULT |
| `S8 NEXT` | 还有件 → S1；无件 → DONE | — | — |

**设计原则**

1. **每步都等事件**（goto 应答 / `motor_angle` 应答 / 图像帧到位），不用固定 `sleep`。
2. **任何失败进 FAULT 并立即停车**，屏幕显示错误码；不重试（时间不够，宁可少抓一件也不要把机构卡住）。
3. **不做抓取复核**（`VERIFY_PICK` 砍掉，省 1.5 s/件；靠闭环 counts 判定）。
4. 显示在每一状态切换时更新，保证"始终有动作/有显示"。

## 6. 关键设计决策（含被否方案）

| # | 决策 | 理由 | 被否方案 |
|---|---|---|---|
| D1 | 通道固定 2 段（Y 让开 → Z 抬起），回程严格反序 | P0 正上方有结构，不能先抬 Z | 先抬 Z 再 Y（撞） |
| D2 | X 只在"最高处"参与移动与对准 | X 参与会破坏"固定通道"的安全前提 | 通道含 X（会被挡） |
| D3 | 转盘用绝对角度 + 单圈归零 | 幂等，重复下发不偏移；断电后人工对 1 号盒 | 相对增量记账（会累积漂移） |
| D4 | 闭环放固件、读遥测缓存 | 判定 1 ms；WiFi 往返 200–400 ms 太慢 | 闭环放上位机 |
| D5 | 查询节流 20 ms + 发帧后静默 30 ms | kHz 级 `0x36` 查询会把 `FD` 运动帧淹掉（已实测） | 不节流（goto 不动） |
| D6 | 分类用"规则(形状\|颜色) + 赛前样本登记" | 现成代码，赛前 30 分钟可录 6 类 | CLIP 零样本（来不及调） |
| D7 | 落货不做视觉确认 | 相机看不到盒区 | 加对射光电（改硬件，赛后） |
| D8 | 显示用派 HDMI 全屏大字（最简） | 赛题强制"仅显示功能的高亮屏" | STM32 直驱 TFT（驱动/接线成本高） |
| D9 | 一键启动 = 界面上一个按钮 + 键盘回车 | 赛题"不得遥控" | 手机/远程触发（违规） |

## 8. 精度与误差预算（粗算，待 M2 修正）

- 编码器：65536 counts/圈，3200 脉冲/圈 → **1 脉冲 = 20.48 counts**。
- 若导程 4 mm：3200 脉冲 = 4 mm → 1 脉冲 = 1.25 µm；**tol 200 counts ≈ 0.25 mm**。
- 视觉链路误差来源：四点校正残差 + 标定残差 + 抓取时爪子偏移。
- **目标**：视觉→脉冲残差 <100 脉冲（≈0.12 mm），夹爪开口留 2–3 mm 余量吸收剩余误差。

## 9. 分类与盒号映射

- 流程：SAM 掩膜 → 颜色(HSV) + 形状(圆度/顶点/长宽比/实心度) → `形状|颜色` 键 → `class_map` → 类别号 → 盒号 = 类别号（1..6）。
- 赛前要做：①6 类各登记 3–5 个样本（GUI「登记样本」）；②确认 `class_map` 6 条键值对应真实类名；③类别→盒号固定映射写进 `config.json`。
- 兜底：分类失败（"待登记"）→ 按**颜色最近**归盒，仍失败 → 放 1 号盒（拿基础分 2 分/件）。
- 现状差距：样本库只有 1 类，`class_map` 值还是旧编号 → **必须重录**。
