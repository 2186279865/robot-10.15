## OPT-01 · 夹爪角度随时可改（松开/预备/夹紧三个值）  `P1`

**问题**
目前 `gripper_open_deg / gripper_ready_deg / gripper_grab_deg` 虽然在参数表里（
`01-交付包/stm32/firmware/Drive/Include/host_protocol_inline.h:95-97`），动作时也确实读参数
（`:1961-1963` `host_cmd_gripper`），但有三层"定死"：

1. 参数只在 **RAM**，MCU 复位/掉电 → 回到默认 180/150/135（`host_params_restore_defaults`，`:133`）；
2. 改起来要跳到「参数」页手填名字+值再点「写入」，夹爪页没有入口；
3. 「舵机夹爪」页只有 夹紧 / 预备(150) / 松开 三个固定按钮，没有"夹到 138 试试"的微调路径。

**方案（分三步，互相独立）**

### 第 1 步 · 界面微调 + PC 端记住（推荐先做，约 1 h，零固件风险）

- 「舵机夹爪」页加三行：`松开 [180] / 预备 [150] / 夹紧 [135]`，每行一个 Spinbox + 「试一下」；
  改值 → 先 `param_set` 再发对应动作，立刻能看到爪子动。
- 三个值落到 `runtime/gripper_angles.json`；**每次连接成功（hello 后）自动下发一遍**，
  换电脑/重装也能恢复。
- 校验：`0 ≤ 夹紧 < 预备 < 松开 ≤ 270`，越界弹提示（防止手滑填 270 顶死机械）。
- 影响文件：`01-交付包/host/host_gui.py`（夹爪页 `_build_gripper` 一带、`_auto_gripper_ready` 里顺带下发）、
  `01-交付包/host/protocol.py`（沿用现有 3 个参数，不加新参数）。
- 局限：**不连笔记本时**（纯上电手动试）仍是固件默认值。

### 第 2 步 · 参数持久化到内部 Flash（推荐做，约半天）★真正"断电不忘"

- Flash 参数区：`magic "R10P" + ver + 21×uint32 + CRC32`；
- 开机 `host_params_load()`：CRC 通过就用存的值，否则用默认；
- 新命令：`param_save`（写 Flash）、`param_defaults`（恢复出厂 + 擦除）；`param_set` 仍只改 RAM（调试不磨 Flash）；
- 安全：只在**四轴全停且未锁存**时允许写；写之前 `host_out` 提示"约 1 秒勿断电"；
- 扇区选择：优先 **16 KB 扇区**（F407 1 MB 的 sector 0–3 是 16 KB，4 是 64 KB，5–11 是 128 KB），
  把擦除时间从"秒级"压到"百毫秒级"；**明天先读一遍内存布局/链接脚本再定，绝不动程序区**；
- 影响文件：`host_protocol_inline.h`（参数表/保存加载/dispatch）、`main.c`（启动时 load）、
  新增 `Drive/Source/flash_param.c` 或直接写进 `*_inline.h`（按现有工程约定，放 inline 更一致）；
- 界面：参数页加「保存到固件」「恢复出厂」+ 写 Flash 期间禁用运动按钮；
- 风险：写 Flash 时主循环会阻塞（擦除期），**比赛运行中绝不保存**，只在赛前存一次；
  另：参数版本 `ver` 变了要能识别旧格式（读失败就用默认，不报错）。

### 第 3 步 · 可选：档位表（P2，以后要多物料再说）

- 把"三个固定名字"升级为最多 8 组 `{name, open_deg, grab_deg}`，序列里写 `grip=soft|hard`；
- 好处：换物料不改参数名、不同盒子可用不同夹紧；代价：参数表 + 协议 + 界面 + 序列全要改。

### 可选增强 · 自适应夹紧（P2，先别做）

夹到目标角后判定"是否夹住"：没夹住就再收 3°，最多 3 次（下限 120°）。
纯软件、不加传感器，但会让节拍多 200–400 ms，且没有电流反馈时"夹住"只能靠停稳判断，
误判风险不小。**建议先用手动微调把那几个物料的角度试出来，再决定要不要自动收。**

**验收**
1. 第 1 步：改 Spinbox → 点「试一下」→ 爪子到新角度；重启上位机后值还在（json）；
2. 第 2 步：改角度 → `param_save` → **断电重启** → 读回仍是新值；`param_defaults` → 回 180/150/135；
3. 全程 `CHECK.py` 19/19 + `selftest.bat` 7/7 不退化。
