## 1. 正确的流程（按你原话画）

```
P0（初始位，转盘正上方，Z 最低）
 │
 ├─ ① 转盘按"绝对角度"转到该类盒（角度模式，幂等）
 ├─ ② 拍照 → ③ 识别定类 → ④ 算目标 X/Y 脉冲
 │

 │      Y 动一点（离开盒子区） → Z 从最低抬到最高 → （此后在最高处自由移动）
 │
 ├─ ⑥ X、Y 走到物块正上方
 ├─ ⑦ Z 下探 → 夹紧 → Z 上抬（抬回到最高）
 ├─ ⑧ 拍照复核（物块是否已离开原位）
 │
 ├─ ⑨ 走回通道末端的 X、Y 坐标（就是"Z 抬到最高那个位置"）
 ├─ ⑩ 倒序回程：Z 降到最低 → Y 回退一点点 → 回到 P0

 └─ ⑫ 屏显 → 拍下一件
```

## 2. 坐标系与固定点（示教一次）

| 名称 | 含义 | 说明 |
|---|---|---|
| `P0` | 初始位 = 转盘正上方 | X0, Y0, Z 最低；松爪落货就在这里 |
| `P1` | 通道末端 = "Z 抬到最高那个位置" | X1, Y1, Z=Z_HIGH；出门最后一步到这儿，回程第一步从这儿起 |
| `Δy_corr` | P0→P1 的 Y 小位移 | 示教得到（"Y 动一点"） |
| `Z_LOW` | 最低（P0 处、回程末端） | 松爪高度 |
| `Z_HIGH` | 最高（通道里、搬运高度） | 所有横向移动都在这个高度 |
| `Z_PICK` | 抓取下探高度 | 爪子抱住物块 |
| `X_OBJ, Y_OBJ` | 物块上方坐标 | 由视觉 → 标定换算得到（每件不同） |

> 通道段 = `[(Y, +Δy_corr), (Z, Z_LOW→Z_HIGH)]`，回程 = 严格反序取反 `[(Z, Z_HIGH→Z_LOW), (Y, -Δy_corr)]`。
> 通道里**不出现 X**；X 只出现在"最高处的自由移动"和"抓取对准"里。

## 3. 转盘：角度模式 + 单圈归零（你指定的做法）

### 3.1 目标

- 上电时人工把 **1 号盒** 对准 P0；
- 发一次"设单圈零点"（`0x93 88` 设零点，或 `0x0A 6D` 清计数）；
- 之后每次只需要说"转到多少度"，驱动器自己记账，**重复下发同一角度不会越转越偏**。

### 3.2 角度表（3200 脉冲/圈，配合 0xFD 绝对位置 `raF=1`）

| 类 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 角度 | 0° | 60° | 120° | 180° | 240° | 300° |
| 脉冲 | 0 | 533 | 1067 | 1600 | 2133 | 2667 |

### 3.3 要固件加的东西（这是本方案唯一的固件新增）

1. **修"绝对当相对"的老 bug**：现在 `control_apply_position()` 调 `Stepper_MoveRelativeAt2(..., 0UL)`，`absolute` 参数没生效 → 需要真走 `Stepper_MoveAbsoluteAt()`（`0xFD raF=1`）。
2. **新命令 `motor_angle,<addr>,<deg_x100>[,<rpm>]`**：
   - `deg_x100` 范围 0..36000（0.00°–360.00°）；
   - 固件换算 `pulses = round(deg_x100 * pulses_per_rev / 36000)`，`pulses_per_rev` 走参数（默认 3200）；
   - 下发**绝对位置**帧（`addr,FD,dir,rpmH,rpmL,acc,pulses,raF=1,snF=0,6B`）；
   - 应答 `#id,ok,addr,deg,pulses`。
3. **新命令 `motor_angle_zero,<addr>`**：发 `93 88`（设当前为零点）→ 单圈归零，回 `ok`。
4. **到位判定**：用 `0x36` 单圈角度回读（遥测里已有 counts）——目标角与实测角差 ≤ 0.5° 即到位；超时/超差 → `E14`（复用现有错误码语义）。
5. 其它轴（X/Y/Z）继续用现有 `motor_goto`（相对闭环），**只有转盘用绝对角度**。

> 这样上位机侧只要说"转到 120°"，不用管当前在哪、上次转到哪——比 v1 的"相对索引记账"稳得多，也正好是你要的"角度控制"。

## 5. 精度与"必须精准"的工程化

1. **每一段都闭环**：X/Y/Z 全部 `motor_goto`，每段 `|err| ≤ tol`（X/Y 建议 tol=100 counts≈0.55°，Z 用 100）；不达标重试 1–2 次，再不行 FAULT。
2. **抓取前视觉复核**：`RECOGNIZE` 要求连续两帧目标坐标差 <8 px 才开抓；抓完 `VERIFY_PICK` 再拍一张确认目标消失。
3. **落点不偏移**：物块在 P0 正上方松爪，靠盒子开口容差吸收（你已确认"到达指定位置就不偏移"）。
4. **转盘绝对角**：重复下发同角度幂等，不会累积误差；每次到位置后回读角差 ≤0.5°。
5. **累计漂移监控**：每 10 件打印一次"P0 处 counts 与上电基准差"，超阈值提示重新对零（不自动清零，避免越描越黑）。
