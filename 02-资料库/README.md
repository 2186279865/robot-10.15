# 02-资料库

> 这里放**所有不是"当前要跑的那一版"**的东西：赛题、硬件资料、往届参考、历史快照、调研报告、交接文档、截图。
> 规则只有一条：**只加不改**。已经写下的资料不删、不改结论；有新认识就新增一份，或在 `00-项目日志.md` 里补一条。

## 与另外两个文件夹的关系

- `01-交付包/` = 能跑的那一版（代码 + 模型 + hex + 部署脚本）。**资料库里的代码都是历史，不要拿它跑。**
- `03-实验台/` = 试过但没进主线的东西（Qwen 语义识别、SAM 上派实测、网络化原型）。
- 本资料库不存大件（模型、venv、编译中间产物）。历史快照里的 `models/` 已被剔除，需要权重去 `01-交付包/vision/models/`。
