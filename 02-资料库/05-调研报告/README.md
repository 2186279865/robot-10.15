## 怎么用这些报告

- 想理解**某个机制的存在理由** → 查对应报告（比如"为什么固件把模块实现写进 `.h`"）。
- 想确认**某个结论是否有证据** → 报告里都是 `路径:行号`，直接跳过去看代码。
- **不要**拿它当"当前代码是什么样"的文档：2026-10-22～23 之后代码改动很大（夹爪三档、接近段示教、回初始位、网络化），以 `01-交付包/README.md` + `VERSION.md` 为准。
