# new_eye 双相机视觉预览（顶视 + 副摄）

面向“夹爪不能旋转、抓起后会遮挡物料”的分拣结构：**所有识别在抓取前完成**。顶视相机负责俯视位置、轮廓与数量；副摄从侧面补充水平位置、高度/侧影信息，两路融合成一份目标列表。程序只写 JSON，不发串口、不动物理机构。

## 运行

```powershell

Qwen\.venv\Scripts\python.exe new_eye\gui.py
```

如果普通方式打不开 USB 摄像头，用管理员方式启动：


## 界面用法

1. 点“扫描相机”，选顶视相机和侧视相机，点“打开双画面”；
2. 顶部“顶视四点框选”：依次点托盘四角（左上、右上、右下、左下，右键撤销）；四点会实时校正成 700×700 的托盘坐标图；
3. 需要双摄融合时再点“副摄四点框选”，同样在副摄画面里**按托盘同一方位**点四角（左上→右上→右下→左下）；主副摄面对面安装时把底部“副摄方向”设为“镜像”或留“自动”；再按副摄装在托盘哪一边选“对齐轴”（自动/左右/前后），融合行会显示它实际选了哪根轴、哪个方向、配上几个；
4. 点“实时分割”：后台线程持续取两路最新帧 → 透视校正 → 前景候选打点 → SAM 实例分割 → 双摄融合，主画面上持续叠加黄色轮廓/外框/红十字/编号；
5. 窗口右侧“目标详情 / 状态”文字面板集中显示所有文字信息：运行状态（实时/单次/登记模式）、刷新帧率、两路相机帧率、分割帧率、融合目标数、**每一步耗时（整帧 / 校正 / SAM 分割 / 反投影 / 副摄 / 融合 / 分类 / 写 JSON）**、各类别计数（未确认项单列为“未确认×N”）、每个目标的明细（编号、类别、形状+颜色、置信度、视角、托盘坐标、面积、来源、投票数、副摄是否印证）、【融合】诊断（顶视/副摄各几个、配上几个、平均 Δu、方向）、以及最近 9 条操作/错误消息；画面里只保留轮廓、框、红十字和编号标签；
6. 灰色/黑色物料在“含灰/黑物料”勾选后启用“与空托盘差分”的分支（先点“采集空托盘”拍一张空托盘背景更稳）；
7. “单次识别”做一次双摄识别（`frames_for_vote` 帧投票分类）并把结果写入 `new_eye/runtime/latest_targets.json`；
8. **分类**：每个目标自动得到“形状|颜色”键并查 `config.json` 的 `class_map`。要教它会认：点“登记样本” → 点顶视画面里的目标 → 输入类别编号或名称（如 `1`、`五棱体·黄`）。登记内容写入 `new_eye/samples.json`，同时把该“形状|颜色”规则写回 `config.json` 的 `class_map` 和 `class_names`，重启后仍有效。没登记过的组合显示“待登记”，不会乱猜。

调试点位、相机索引和旋转角度后点“保存配置”，下次打开自动使用。

## 工作方式

1. 两路画面各按四点透视校正到 700×700 托盘坐标；
2. 先用颜色（饱和度）或“与空托盘的灰度差”找候选前景块，只在候选块内部撒提示点；
   SAM 负责把候选块细化成实例掩膜——空托盘、阴影、反光没有候选，就不会再报“空的地方有物体”；
3. 掩膜再按面积、贴边、候选前景占比、物体性（饱和度/差分亮度）过滤，并按 IoU/包含关系去重；
4. 顶视结果为主；副摄在同一托盘坐标系里按水平位置 u 印证顶视目标（同一列前后重叠的物体允许共用一块侧影，副摄分不出前后），副摄多出来的目标作为 side-only 追加；
5. 两路左右方向相反时自动翻转对应关系；融合时保留顶视的 bbox/中心点，副摄信息作为附加字段；
6. 分类不训练模型，用“规则特征 + 现场登记”：颜色取掩膜内部（先腐蚀掉高光/边缘）HSV 中值，形状用圆度、多边形顶点数、长宽比、实心度；圆形顶面若副摄侧影顶部明显收窄则判“球”而不是“圆柱/圆形”；拼成 `形状|颜色` 键后查 `config.json` 的 `class_map` → 现场登记的 `samples.json`（同键/特征最近邻）→ 都没有则标“待登记”（`need_review: true`），不硬猜；
7. 输出按 v 坐标排序，`schema_version=5`，`motion_authorized` 恒为 `false`。

## 输出 JSON

`schema_version`（当前 5）、`motion_authorized`、`max_classes`、`classification_logic`、`class_summary`（各类别计数）、`targets`。每个 target：

- `id`、`views`（`top+side` / `top` / `side`）、`confidence`；
- `bbox`、`center_px`、`area_px`：顶视原图坐标（side-only 目标为副摄原图坐标）；
- `bbox_warped`：700×700 托盘坐标；
- 双摄都看到时额外附带 `side_bbox`、`side_center_px`、`height_ratio`（副摄框高/700，可作高度特征）；
- 分类字段：`shape`/`shape_conf`、`color`/`color_conf`、`class_id`、`class_name`、`class_key`（`形状|颜色`）、`class_conf`、`class_source`（`rule` / `sample-key` / `nearest` / `registered` / `unknown` / `side-only`）、`need_review`、`class_votes`（单次识别的投票命中数，如 `5/5`）。`need_review: true` 表示还没教过这个组合，应先登记。

## 标定

编辑 `config.json`：两个相机索引、分辨率、顶视/副摄四角点、旋转角、像素到毫米比例。没有标定时仍能预览和识别，但 `motion_authorized` 始终为 `false`。

分类相关的可选配置：

- `class_map`：键是 `形状|颜色`，值是类别编号。形状取 `圆柱/圆形`、`三棱体/三角形`、`正方体/正方形`、`长方体/长方形`、`五棱体`、`其他几何体`、`球`；颜色取 `红`、`黄/橙`、`绿`、`蓝/浅蓝`、`紫/其他`、`黑`、`浅色/白`。例：`"五棱体|黄/橙": "3"`；
- `class_names`：编号到显示名的映射（登记时自动写入）；
- `side_shape_refine`（默认 true）：用副摄侧影顶部收窄程度区分“球/圆柱”；
- `sample_similarity`（默认 0.88）：特征最近邻接受阈值。


## 通讯（把识别结果发给机器人）

1. GUI 顶栏勾 **“网络推送”**，日志会显示本机 IP 和端口（默认 5055）
2. 机器人端（香橙派/另一台电脑，无线/有线都行）：
   `python new_eye/link_robot_example.py` —— 会自动发现视觉端（UDP 5056 广播），不用记 IP
   找不到时再写死：`python new_eye/link_robot_example.py <笔记本IP> 5055`
3. 每帧 JSON 里 `targets[].u / v` 是托盘归一化坐标（0~1），乘托盘实际长宽即得抓取点
4. 要转发给单片机：`python new_eye/link_robot_example.py <IP> 5055 /dev/ttyUSB0 115200`

协议细节（JSON 字段、0xAA55 串口帧、CRC16）见 `new_eye/link.py` 顶部注释和
`new_eye/交接文档.md` 第 19 节。首次使用记得放行 Windows 防火墙 5055 端口。
