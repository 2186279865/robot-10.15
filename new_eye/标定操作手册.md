# X/Y 标定 + 示教 操作手册（一步一步照做）

> 目标：让机器人知道「画面里的 (u,v) → 该走多少 X/Y 脉冲」。
> **默认模式：手动走轴 + 视觉记录**——你在单轴页自己走 X/Y，向导用“单轴页的命令脉冲（软位置）”
> 和 new_eye 每次「单次识别」给出的 u/v 配对，最后解出 2×2 仿射矩阵。
> 不需要编码器回读，不需要掐到位时间，也不需要改固件。
> 手放急停旁；标定完再示教 Z 高度和放料工位。
> 一个人做就行：new_eye 点识别 → 上位机点两个按钮 → 单轴页走两步，循环 4 次。

---

## 第 0 步：安全检查（30 秒）

- [ ] **顶视（主摄）画面**里只放 1 个物块，且它要在**四点框选出来的托盘区域内部**
- [ ] 位置放在这个区域的**中间附近**，左侧、上方留出走轴距离（u≈0.35~0.50、v≈0.35~0.50）
  - 每个轴要能推到 2~3 个明显不同的位置；**单次推动量 < 1/3 圈**（单圈编码器只能测最短路径，推太多方向会判错）
- [ ] 机械臂 Z 停在**安全高度**，X/Y 上方没有会撞的东西
- [ ] 手推前先点“取消 X/Y 使能”（没有保持力矩才能推动）；推平台/皮带，别硬掰电机轴
- [ ] 急停按钮在手边；知道点「停止所有轴」能停

## 第 3 步：打开标定向导（两种模式）

- [ ] 上位机 →「视觉目标」页 → 点「标定向导（u/v → X/Y 脉冲）」
- [ ] 模式默认是 **「视觉点标注（推荐）」**；旧办法是「手动走轴 + 视觉记录」
- [ ] **不需要** new_eye 开实时分割

### 3A. 视觉点标注法（推荐：不用走轴记数据，只用点画面 + 对爪子）

1. new_eye 顶视画面右下方点 **「标注点」**（按钮变「结束标注」）
2. 在画面里点 3~6 个**分散**的位置（物块中心、贴纸、托盘上的记号都行），每点一次顶视画面上出现青色 `P1/P2/...` 十字；右键撤销上一个点
3. 点 **「结束标注」**（文件已自动存到 `new_eye/runtime/calib_marks.json`）
4. 到向导里（模式选「视觉点标注」）点 **「刷新标注点」**，列表出现 `P1 u=… v=…  X=— Y=—`
5. 用**单轴页**把**夹爪中心**移动到 P1 对应的那个物理位置正上方
6. 选中 `P1` 行 → 点 **「记录爪位」** → 该行出现 `X=… Y=…`（自动跳到下一个没记的点）
7. 对 P2、P3… 重复 5~6 步（每个点都要用同一个“爪子中心”去对，别一会儿用指尖一会儿用块中心）
8. 全部记完后点 **「求解并保存」** → 日志出现残差与方向检查，写 `new_eye/tray_calib.json`

> 为什么推荐：点的位置由视觉给、爪位由电机给，**不需要沿固定方向走**、不需要回 0、
> 也不会因为三点共线报“矩阵奇异”；只要点分散（不要都在一条线上），3 个点就能解。

> 对爪子时不用来回切页面：向导底部有 **「XY 点动」**——`X+ / X− / Y+ / Y−` 四个键，
> 按键下面一行是**可改的脉冲数**（默认 500，点一下走这么多），旁边有「停止所有轴」和
> `X 方向取反 / Y 方向取反`。点动会自动先使能，走的脉冲一样记进软位置，所以记录爪位前用它微调是安全的。

### 3B. 手动走轴 + 视觉记录（旧办法，仅当不想用标注点法）

- [ ] 模式选 **「手动走轴 + 视觉记录」**
- [ ] 每次移动后用「单次识别」出一帧就够
- [ ] 向导只负责**记账**（u/v + 软位置脉冲）和**算矩阵**，轴由你自己用单轴页走

手动走模式控件：

| 控件 | 说明 |
| --- | --- |
| 只标目标编号 | 画面里有多个物块时填 `3`（对应 #3）；只有 1 个就留空（默认取离托盘中心最近的） |
| ① 读取视觉 u/v（不运动） | 读 new_eye 最新一帧里的 u/v，只读不动 |
| ② 记录坐标（u/v + 当前脉冲） | 把“刚才读到的 u/v + 当前 X/Y 软位置”存成一个采样点 |
| 读取现在走过的脉冲 | 显示当前软位置，以及相对上一个点的 ΔX/ΔY，用来核对 |
| 一键回 0 脉冲点（X/Y） | 按软位置把 X/Y 开回 0（= 最近一次「位置清零」的位置） |
| 撤销上一个点 / 清空采样 | 记错了就撤/清 |
| ③ 求解并保存标定文件 | ≥3 个点后求解，写 `new_eye/tray_calib.json` |
| 采样列表 | 每点 u/v + 脉冲 + 与前一点的 Δ，方便核对 |

> 脉冲从哪来：上位机会给每台电机记“软位置”——你在单轴页每点一次「▶ 相对走」，
> 它就按命令脉冲数累加。所以**只用「▶ 相对走」**；「▶ 连续走」「▶ 绝对走到此」会让软位置变成“未知”。
> 点「位置清零」会把软位置归 0，并把“0”定义成当前位置。

## 第 4 步：走一遍循环（仅 3B 手动走轴法需要，5~10 分钟）

记 3 个点就能出结果（4 个更稳，能看出残差）。**最省事的做法**是只走两次：

- [ ] 单轴页把 X/Y 放到位置 1（可以用相对走，也可以先走 X 再走 Y）
- [ ] new_eye 点一次 **「单次识别」**
- [ ] 向导点 **「① 读取视觉 u/v」**（日志里会出现 `视觉：#1 u=… v=…`）
- [ ] 向导点 **「② 记录坐标」** → 出现 `点 1：… → X=… Y=… 脉冲`
- [ ] **只动 X**（单轴页 X 面板相对走 3000 脉冲）→ 单次识别 →「① 读取」「② 记录」→ 点 2
- [ ] **只动 Y**（单轴页 Y 面板相对走 2500~3000 脉冲）→ 单次识别 →「① 读取」「② 记录」→ 点 3
- [ ] 点 **「简化求解（只走 X/Y）」** —— 它假设 X 走时画面左右（u）变、Y 走时前后（v）变，
      不需要点摆成三角形，**不会再报“矩阵奇异/共线”**
- [ ] 想更稳：再斜着走一次（同时动 X 和 Y）记点 4，仍用「简化求解」；残差和耦合会在报告里显示

> 如果想要“完整仿射”（允许 X/Y 斜装、相机旋转），就走成三角形（X 一次、Y 一次、再斜一次或回 0 后换个位置），
> 点 **「③ 求解并保存」**；万一还是报共线，对话框会问你要不要自动改用简化法。

> 为什么要「一键回 0」：所有点的脉冲最好都相对同一个 0 点，误差最小。
> 走到第 4 个点后点「一键回 0」，它按软位置把轴开回 0；等停下后点「读取当前脉冲」确认是 `X=+0 Y=+0`。
> 如果不想回 0 也能算（相对累计），但中间只要有一次位置清零/断线就乱了。

## 备选：手推 + 编码器回读模式（只有平台能反向推动时才用）

滚珠丝杠、蜗轮蜗杆等自锁机构**即使取消使能也推不动**，这是正常的，不是向导坏了。
确认平台能被手推动（皮带/同步带）才用这个模式：

- [ ] 先点 XY 点动区的 **「取消使能 X/Y」**（会先 stop_all，再对 4/5 轴发 motor_enable 0）→ 试着推
- [ ] 推得动之后再点 **「读回读脉冲」**：日志会显示 `回读：X=… counts（≈… 脉冲）`，确认计数会随推动变化
- [ ] 模式选「手推 + 编码器回读（备选）」→ 推到位置 A（停 1 秒）→ new_eye「单次识别」→
      向导「记录当前位置（视觉 + 回读）」
- [ ] 再推 2~4 个点（X 方向一次、Y 方向一次、斜着一次），每次推 **< 1/3 圈**
- [ ] 「求解并保存标定文件」→ 最后点「恢复 X/Y 使能」（或 XY 点动区的「使能 X/Y」）

> 原理：编码器回读 65536 counts/圈、运动 3200 脉冲/圈，所以 1 脉冲 ≈ 20.48 counts；
> 单圈编码器只测最短路径，所以单次推动不能超半圈（向导会把 >0.45 圈的跳变标出来）。

> **“记录爪位”会用哪一路数据？** 两轴都有 2.5 秒内的新鲜回读 → 用回读计数换算（更准）；
> 否则退回软位置（向导日志会标“来源 回读 / 软位置”）。所以手推之后先点一次「读回读脉冲」再记录最稳。

## 第 9 步：示教 Z 和放料工位（标定之后做）

编辑 `ghr/10.15/上位机/vision_grasp.json`，单位都是**脉冲绝对值**（用单轴页面的位置读数）：

| 键 | 含义 | 怎么得到 |
| --- | --- | --- |
| `z.safe` | 安全高度（移动 X/Y 时停这） | 面板升到物块顶上方 1~2cm，读 Z |
| `z.grasp.<类别名>` | 每类下爪高度 | 手动低速下到能夹住该物块，读 Z |
| `z.lift` | 抓后抬起高度 | 抓住后抬到不会蹭到其他物块，读 Z |
| `z.place` | 放料下降高度 | 到盒子上方，下到能放稳，读 Z |
| `drop.x` / `drop.y` | 固定放料工位 X/Y | 手动移到放料点，读 X/Y |
| `speed.rpm` / `speed.travel_rpm` | 抓取/移动速度 | 先 40 / 120，稳了再调 |
| `tray.start_box` | 转盘现在在哪个盒 | 1..6，或点“转盘记忆重置为盒1” |
| `dir_positive` | 方向字段“正”的取值 | 默认 0；若轴反了改 1 |

> 类别名必须和 new_eye `class_map` 的类别名一致（比如「圆柱/圆形」「五棱体」），
> 否则会 fallback 到 `z.lift` 并给 warning。

## 排查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 读取视觉报「已过期」 | 数据 > 15 秒 | 回 new_eye 点「单次识别」 |
| 读取视觉报「没有目标」 | 识别失败/物块不在画面 | 检查实时分割，先确认能框到物块 |
| 软位置显示“未知” | 用过「连续走」「绝对走到此」，或断线重连过 | 用相对走把平台挪回 0 基准点，再对 X/Y 点「位置清零」，重新标 |
| 「一键回 0」报位置未知 | 同上 | 手动挪回基准 + 位置清零 |
| 记录时 ΔX/ΔY 都是 0 | 单次识别后没重新读取视觉，或点重复 | 每换位置都要：单次识别 → ①读取 → ②记录 |
| 求解报「标定点不合格：视觉几乎没动」 | 点太集中 / 两次识别画面没变 / 轴没动 | 点分散开（单次 2000~3000 脉冲），确认物块真的在画面里移动 |
| 手推时 counts 一直不变 | 该轴没接回读线（TXD→PA3）/`readback_mask` 没开/查询超时 E04 | 点「读回读脉冲」看回读轴列表；固件对没接回读的轴直接回 E04/E11（不会编数）。查线或改用软位置 |
| 点「取消使能」后推不动 | 丝杠自锁 / 驱动器使能硬接线 / 失能帧驱动器未应答 | 正常现象，用手动走轴或标注点法；日志里若能看到 `motor_enable ok` 说明命令到了驱动器，推不动就是机构自锁 |
| 「读回读脉冲」显示 `回读轴：无` | 握手没报回读轴（四路 TXD 没并到 PA3 / readback_mask=0） | 查参数页 `readback_mask`，或先只用软位置标定 |
| 记录爪位来源是“软位置”但平台是手推出来的 | 回读超过 2.5 秒没刷新 / 只接了一路回读 | 记录前先点「读回读脉冲」；两轴都要有回读才能用回读路径 |
| 某次 ΔX/ΔY 明显偏大且方向不对 | 单次推过半圈，编码器按最短路径判反了 | 撤销这个点，推小一点（< 1/3 圈） |
| 求解报「矩阵奇异/标定点可能共线」 | 三个点在画面里几乎排成一条线（最常见：只走了一个方向） | 直接点 **「简化求解（只走 X/Y）」**；或补一个斜向点再「③ 求解并保存」 |
| （标注点法）点「刷新标注点」列表是空的 | 还没在 new_eye 里点「标注点」/ 没点「结束标注」/ 文件不在 | 看日志里的文件路径 `new_eye/runtime/calib_marks.json`；确认点在四点多边形内部 |
| （标注点法）某行 `X=— Y=—` | 该点还没记录爪位 | 选中该行 → 把夹爪移到该物理点 → 「记录爪位」 |
| （标注点法）残差很大/方向反 | 对点不准（没对爪子中心）、点太挤、或 X/Y 轴号接反 | 重新对点（点分散、每次用同一“爪子中心”）；核对 X=4、Y=5 |
