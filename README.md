## 最快上手

```bat
cd 01-交付包
setup.bat                     :: 只需一次：建 .venv 并装依赖（约 1–2 GB）
run.bat                       :: 本地模式：相机 + STM32 都插在本机
run.bat --pi 192.168.100.198  :: WiFi 模式：相机和 STM32 在派上（端口下拉框会自动出现「派 robot-pi …」）
run.bat --sim                 :: 没有硬件，纯看界面
selftest.bat                  :: 自测 7 步（220 单测 + 端到端 + GUI）
```

派端装一次：`cd 01-交付包/orangepi && ./install.sh`（装依赖 + 生成开机自启服务）。
固件烧录：`01-交付包/stm32/hex/STM32F429.hex`（或 Keil 打开 `01-交付包/stm32/firmware/Project/STM32F407.uvprojx` 按 F8）。

## 三个容易踩的坑（交付包里已经处理过，但你还会遇到）

1. **相机槽位每次插拔可能变**——顶视/侧视互换后要改 `vision/config.json` 的 `remote.cam_map`；
2. **两台相机别挂同一个 USB2 hub**——带宽不够会掉到 5 fps，插一台到 USB3；
3. **动过相机位置/分辨率 → 标定全部重做**（四点、空背景、X/Y、Z 示教）。

## 约定

- 批处理文件一律**纯 ASCII + CRLF**（cmd.exe 逐字节解析，UTF-8 中文会把行切错）；
- 固件里**不要**从外部脚本改 `.uvprojx`（Keil 保存会用内存里的旧列表覆盖）；
- 新增功能优先改 `*_inline.h`；`Drive/Source/gripper.c`、`stepper.c` 是参考副本、不进编译；
- `01-交付包` 严禁 import `03-实验台` 里的东西；要用的结论就搬进 01。
