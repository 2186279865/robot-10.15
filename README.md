2. [CONTRIBUTING.md](ghr/10.15/CONTRIBUTING.md) —— 精简版协作规范

**在这个工程里务必先看"三条铁律"**，尤其是：

- `ghr/10.15/MY/main.c` 里的 `*_inline.h` **是模块实现代码，不能删**
- 不要在没有沟通的情况下改 Keil 工程文件（会被 Keil 覆盖）
- 源文件是 **GBK / UTF-8 混合编码**，不要批量转码

## 硬件引脚分配

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| 舵机（抓夹） | **PB6** | TIM4_CH1，50Hz PWM | 500~2500us ↔ 0~270°，上电停在松开位（180°） |
| 按键 | **PA0** | GPIO 输入，**内部下拉** | ⚠️ **按下读到高电平**（照例36 的写法） |
| 步进电机 | **PA2** | USART2 TX，115200 8N1 | 只发不收，PA3 留空；多台靠地址区分（Z=1 托盘=3 X=4 Y=5） |
| 板载 LED | **PC13** | GPIO 输出 | 低电平点亮 |

**电源**：步进驱动器需独立 12~48V 电机电源，舵机需 4.8~7.4V；**都要和 STM32 共地**。
