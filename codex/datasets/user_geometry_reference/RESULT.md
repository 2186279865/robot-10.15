# 用户示意图实测

2026-10-27，在本机 RTX 5060 Laptop 8GB 上测试。不需要对图中物块训练，未访问云端。

输入是用户提供的渲染示意图。先去掉底部英文类别标签，SAM 全图分割并过滤背景和重复面片，得到 9 个物块，再对裁剪边界绿色描边做局部修复。原图与未修复裁剪均保留。分类使用 `qwen3-vl:4b-instruct`，候选包括常见几何体和“不确定”，未给模型提供每块的类别标签。人工参考类别来自原图底部组名。

| 编号（从左到右分组） | 颜色统计 | 原图类别 | 模型结果 | 用时 |
|---|---|---|---|---|
| 1 | 蓝 | 三棱柱 | 三棱柱 | 58.0 秒，含冷启动 |
| 2 | 紫 | 三棱柱 | 三棱柱 | 1.20 秒 |
| 3 | 绿 | 三棱柱 | 三棱柱 | 1.23 秒 |
| 4 | 紫 | 六棱柱 | 六棱柱 | 1.19 秒 |
| 5 | 绿 | 六棱柱 | 六棱柱 | 1.27 秒 |
| 6 | 红 | 六棱柱 | 六棱柱 | 1.29 秒 |
| 7 | 黄 | 菱面体 | 三棱柱，误判 | 1.40 秒 |
| 8 | 紫 | 菱面体 | 菱面体 | 1.62 秒 |
| 9 | 红 | 菱面体 | 六棱柱，误判 | 1.32 秒 |

本次形状结果 7/9，约 77.8%，9 次接口均成功。热启动单件约 1.2~1.6 秒；全图 SAM 分割另需约 11~30 秒（两次进程测量，含初始化差异）。以上不是完整画面的实时速度。颜色来自像素统计，缺少独立颜色及镂空人工标注，不报告其准确率。没有镂空样本，不能推断孔洞效果。单张渲染图的结果不能代表现场实拍准确率。

失败样本保留为 7、9，不能靠写死图中分组标签解决。优先补充同一物块的另一视角，固定白平衡、光照和背景，再用现场图片对比本地/云端。实时方案可采用快速轮廓/颜色持续刷新，对稳定新目标异步调用视觉模型，完成后缓存类别；全图 SAM 作为粘连时的补充分割，避免每帧都跑。

复现：在 codex 中先启动 `run-local.bat`，再使用同一 Python 运行：

```powershell
python main.py --benchmark datasets/user_geometry_reference/labels.json --backends local
```

完整原始报告在 `runtime/reference/local-benchmark.json` 和 `.csv`，结果图在 `runtime/reference/local-annotated.png`。runtime 不纳入版本控制。
