# 笔记本 + 树莓派 同 WiFi 组网指南（无互联网也能用）

> 目标：让笔记本和派在**同一个局域网**里互相 ping 通、5057/5058 能连。
> 局域网 ≠ 互联网。没有外网完全不影响，甚至更稳（没有 DHCP 变动、没有随机化 MAC）。

---

## 0. 一分钟决策表

| 场景 | 推荐方案 | 谁当网关 | 稳定性 |
|---|---|---|---|
| 比赛现场、要求最稳 | **方案 C：便携 5 GHz 路由器**（或手机热点） | 路由器 | ★★★★★ |
| 只有两台设备、临时演示 | 方案 A：笔记本开热点 | 笔记本（192.168.137.1） | ★★★☆ |
| 想让派自己当热点 | 方案 B：派开 AP | 派（192.168.4.1） | ★★★ |
| 比赛允许拉网线 | 方案 D：网线直连（USB-C 网卡） | 无 | ★★★★★ |

---

## 方案 A：Windows 笔记本开热点（最省事）

1. 设置 → 网络和 Internet → 移动热点 → 打开。
   - Win11 可在"编辑"里把频段设为 **5 GHz**、SSID/密码自定义。
   - 共享方式选"无"也可以（WLAN 热点不依赖上游，但要本机已连一个网络才能打开时，可先连手机热点当上游，开完再断开）。
2. 笔记本在热点网络里的地址**通常是 192.168.137.1**（在"移动热点"页或 `ipconfig` 里确认）。
3. 派连这个热点（见方案 B 的 wpa_supplicant 写法，把 SSID/密码换掉）。
4. 笔记本上给派一个固定地址更省事：路由器/热点一般会保留 DHCP 记录；不确定就在派上设静态 IP，例如 `192.168.137.50`。

**老系统/无移动热点开关时**用命令行：
```powershell
netsh wlan set hostednetwork mode=allow ssid=ROBOT-5G key=12345678
netsh wlan start hostednetwork
netsh wlan show hostednetwork
```

**注意**：Win11 家庭版有时会禁用"移动热点"（灰掉）。此时按方案 C 走，别在比赛现场折腾。

## 方案 B：派当热点（不需要笔记本开热点）

```bash
# 派上（Raspberry Pi OS Bookworm，NetworkManager）
sudo nmcli device wifi hotspot ifname wlan0 ssid ROBOT-PI password 12345678
sudo nmcli connection show      # 看 Hotspot 连接名
```
默认网关地址 `10.42.0.1`（NetworkManager hotspot）或 `192.168.4.1`（hostapd 方案）。
笔记本连 `ROBOT-PI` 后 `ping 10.42.0.1`；派端 IP 就是网关地址。

hostapd 经典写法（旧系统/需要 5 GHz）：
```bash
sudo apt install hostapd dnsmasq
sudo iw list | grep -A6 "Supported interface modes"   # 确认有 AP
sudo iw reg set CN
# /etc/hostapd/hostapd.conf
interface=wlan0
driver=nl80211
ssid=ROBOT-PI
hw_mode=a            # 5 GHz；2.4 GHz 用 g
channel=149
wpa=2
wpa_passphrase=12345678
wpa_key_mgmt=WPA-PSK
```
配合 dnsmasq 给笔记本发 192.168.4.x 地址。

## 方案 C：便携路由器（比赛首选）

- 5 GHz、关掉"访客网络/AP 隔离"（隔离会让两台设备互相看不见）。
- 在路由器后台给笔记本和派做 **DHCP 静态绑定**（按 MAC），IP 永远不变。
- 断网也照常工作：路由器只是交换机 + DHCP，不需要 WAN。
- 现场注意：如果场馆 WiFi 很挤，选 5 GHz 高频段（149/153/157/161），别用 2.4 GHz。

---

## 方案 D：网线直连

- 笔记本用 USB-C/USB3 千兆网卡，网线直连派。
- 没 DHCP 时双方自动拿 `169.254.x.x`（链路本地地址），互相能 ping（Windows/macOS 都支持）。
- 更稳：手动静态 IP，笔记本 `192.168.50.1/24`，派 `192.168.50.50/24`。

## 通用必做（两分钟，能省两小时）

### 笔记本侧
```powershell
# 1) 网络类别设为"专用"，否则 Windows 防火墙会拦入站
Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private

# 2) 放行 5055-5059（TCP + UDP）
New-NetFirewallRule -DisplayName "Robot 5055-5059" -Direction Inbound `
  -Protocol TCP -LocalPort 5055-5059 -Action Allow -Profile Private
New-NetFirewallRule -DisplayName "Robot UDP 5056" -Direction Inbound `
  -Protocol UDP -LocalPort 5056 -Action Allow -Profile Private
```
（`10.21/net/firewall-allow.ps1` 已包含这两条，管理员 PowerShell 直接跑。）

### 派侧
```bash
sudo iw dev wlan0 set power_save off          # 关省电，否则延迟抖动大
sudo systemctl disable --now bluetooth         # 可选，减少 2.4 GHz 干扰
ip -4 addr show wlan0                          # 确认 IP
hostname -I
ping -c 3 <笔记本IP>
```
建议给派配**静态 IP**（`/etc/dhcpcd.conf` 或 NetworkManager 的 `ipv4.method manual`），别依赖 DHCP 保留。

### 两端验通
```powershell
ping <派IP>
Test-NetConnection <派IP> -Port 5057
Test-NetConnection <派IP> -Port 5058
python 10.21\net\find_pi.py                       # 自动发现 + 体检
python 10.21\net\find_pi.py <派IP> --full          # 再加取帧测速
```

### 测带宽/延迟（可选但强烈建议）
```bash
# 派上
sudo apt install -y iperf3 && iperf3 -s
```
```powershell
# 笔记本上（iperf3.exe 自带或用 winget install iperf3）
iperf3 -c <派IP> -t 10 -P 4
```
5 GHz 正常应 > 100 Mbps；远低于 100 Mbps 说明信号弱/2.4 GHz 拥挤/开了省电。

## 离线部署（现场很可能没网）

1. 笔记本上先把 Python 依赖装好（`10.21/setup.bat`），一次成功后就与网络无关。
2. 派的依赖在**有网时**就装好（`10.21/pi/install.sh`）。若必须离线，先把 wheel 下到 U 盘：
   ```powershell
   python -m pip download -r 10.21/pi/requirements-pi.txt -d wheels --only-binary=:all: `
     --platform manylinux2014_aarch64 --python-version 311 --implementation cp
   ```
   到派上 `pip install --no-index --find-links wheels -r requirements-pi.txt`。
3. 模型 `vision/models/sam_b.pt`（375 MB）已经在 `10.21/` 里，不需要联网下载。
4. 所有文档都在 `10.21/docs/`，不依赖外部链接。

## 比赛前 10 分钟自检清单

- [ ] 路由器/热点已开，5 GHz，AP 隔离关闭
- [ ] 笔记本 IP 与派 IP 同网段（`ipconfig` / `hostname -I`）
- [ ] `ping` 通、`Test-NetConnection <派IP> -Port 5058` = True
- [ ] `python 10.21\net\find_pi.py <派IP> --full` 取帧成功、耗时 < 100 ms
- [ ] 派端 `pi_agent.py` 已启动（或 systemd 已 enabled）
- [ ] STM32 串口在派上枚举（`ls /dev/ttyACM*`），`pi_agent` 显示串口已打开
- [ ] 上位机连上 `tcp://<派IP>:5058`，日志出现 `hello` 应答
- [ ] 视觉页双画面都出图（顶视 0、侧视 1）
- [ ] 点「停止全部」能停（第二层：拔掉笔记本网线，1.5 s 后机械臂也自己停 → 安全网有效）
- [ ] 电源、舵机独立供电、共地（老规矩）

## 常见故障

| 现象 | 排查 |
|---|---|
| 笔记本搜不到热点 | 网卡不支持 AP 模式；换方案 C；或手机热点 |
| 能 ping 通但 5057 连不上 | Windows 防火墙 / 派端服务没起 / 端口写错 |
| 连上一会儿就断 | 派 WiFi 省电（`power_save off`）；信号弱；USB 相机抢带宽（把 USB3 相机单独插 USB3 口） |
| 延迟大（取帧 > 300 ms） | 2.4 GHz 拥挤、信号弱、JPEG 质量太高（降到 60）、分辨率降到 1280×720 |
| 派 IP 每次变 | 静态 IP 或路由器 DHCP 绑定 |
| 两台设备互相不可见 | 路由器开了 "AP 隔离/客户端隔离" |
| 手机热点名带中文/特殊字符 | 改成纯英文 SSID |
