# 烧录与编译（STM32 侧）

本目录 `stm32/` 是四轴抓取固件的完整源码 + Keil 工程 + 现成 hex。

```
stm32/
├── firmware/          # 源码
│   ├── MY/            # main.c / main_diag.c / stm32f4xx_it.c / stm32f4xx_conf.h
│   ├── Drive/         # 驱动
│   │   ├── Include/   #   ★ 模块实现都在 *_inline.h（main.c 用 #include 引进来）
│   │   └── Source/    #   led.c / delay.c / servo.c 参与编译；gripper.c / stepper.c 是参考副本，不进编译
│   ├── STM32/         # CMSIS + STM32F4xx 标准外设库
│   └── USB/           # USB Device 库（CDC 虚拟串口）
├── project/           # Keil 工程 STM32F407.uvprojx（另有 _diag 诊断工程）
├── hex/               # 编译产物：STM32F429.hex（主）、STM32F429_diag.hex（诊断）
├── docs/              # EMM V5 串口协议与工程指令总结
└── tools/keilkilll.bat
```

## 1. 直接烧（不需要编译）

用 **STM32CubeProgrammer** 或 **ST-LINK Utility**：

1. 板子接 ST-Link（SWD：SWDIO / SWCLK / GND / 3V3）；
2. 打开 `stm32/hex/STM32F429.hex`；
3. 点 Download，烧完复位。

> 文件名 `STM32F429` 是历史遗留命名，**芯片实际是 STM32F407ZGT6**，MDK 目标名也是 `STM32F407`。这不影响烧录。

## 2. 用 Keil 编译 + 下载

环境要求（这台机器上已验证）：

| 项 | 值 |
|---|---|
| Keil MDK-ARM | V5.39 |
| 编译器 | **ARMCC V5.06 update 6**（不能用 AC6，工程是 C99 + 标准外设库写法） |
| 器件包 | Keil.STM32F4xx_DFP.3.1.1 |
| 芯片 | STM32F407ZGTx（鹿小班 LXB407ZG-P1） |

步骤：双击 `stm32/project/STM32F407.uvprojx` → 接 ST-Link → **F8**（Download）。

命令行编译（不打开 GUI）：

```bat
"D:\study\keil\UV4\UV4.exe" -b "stm32\project\STM32F407.uvprojx" -j0 -o "build.log"
```

- 退出码 0 = 成功；日志里要看到 `0 Error(s), 0 Warning(s)`。
- 日志实际写在 `project/Objects/STM32F429.build_log.htm`（Keil 自己的位置）。
- 第一次编译前若报 `cannot create command input file '.\objects\xxx.__i'`，是 `Objects/` 目录不存在 → 手动建一个 `stm32/project/Objects` 再编译。

## 3. 两条必须知道的工程约定（改了会炸）

1. **模块实现写在 `Drive/Include/*_inline.h` 里**，`MY/main.c` 顶部用 `#include` 把它们引进来。所以：
   - 改功能 → 改 `*_inline.h`（不是 `.c`）；
   - `Drive/Source/gripper.c`、`stepper.c` 是**参考副本，不参与编译**，加进工程会 `Multiply defined`；
   - 例外：`Drive/Source/servo.c` 真的参与编译。
2. **不要从外部脚本改 `.uvprojx`**：Keil 保存时会用内存里的旧文件列表覆盖它。要加文件就在 Keil 界面里加。

另：源文件编码是 GBK/UTF-8 混合（`MY/main.c` 等是 GBK）。**不要批量转码**，用支持指定编码的编辑器改。

## 4. 硬件接线速查

| 功能 | 引脚 | 说明 |
|---|---|---|
| 四台 EMM V5 步进 | PA2 = USART2_TX | 115200 8N1，只发不收；地址 Z=1、托盘=3、X=4、Y=5 |
| 编码器回读（预留） | PA3 = USART2_RX | **当前未接线**，所以 `motor_query` 一律 `E04` |
| 舵机夹爪 | PB6 = TIM4_CH1 | 50 Hz，500–2500 us 对应 0–270° |
| 按键 | PA0 | 必须**内部下拉**，按下读到高电平 |
| LED | PC13 | 低电平点亮 |
| 上位机串口 | USB CDC | VID:PID = 0483:5740，插上就是 COMx / /dev/ttyACM0 |

电源：驱动器独立 12–48 V，舵机 4.8–7.4 V，**必须共地**。

## 5. 夹爪角度（当前版本）

| 角度 | 含义 | 什么时候到 |
|---|---|---|
| 180° | 完全张开 | 上电初始 / 松开货物 |
| 150° | 预备位 | 上位机连上后自动下发（`gripper ready`） |
| 135° | 夹紧 | 抓取时（`gripper grab`） |

对应固件参数：`gripper_open_deg` / `gripper_ready_deg` / `gripper_grab_deg` / `gripper_hold_max_ms`（0 = 一直通电保持；>0 = 保持超时后卸力，默认 0）。

## 6. 诊断固件

`hex/STM32F429_diag.hex` 是 10 月 16 日的诊断程序（FD 位置模式每 2.5 秒半圈、LED 闪 2 下），只在"怀疑硬件/驱动器"时用，不是主固件。
