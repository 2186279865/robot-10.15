# 在另一台电脑复刻本项目（完整流程）

> 适用：Windows 10/11 x64。仓库里已有**全部源码与文档**，但**不含** Python 虚拟环境、模型权重、编译产物和日志。
> 换机 = 克隆源码 + 按需重建这些"可再生成"的目录。
> 建议克隆到**同一路径** `D:\study\project\robot-competition`——项目里多处文档和 `new_eye\config.json` 写的是绝对路径。

---

## 0. 先确定要复刻到哪一层

四层可以独立停，越往下需要的东西越多：

| 层级 | 内容 | 额外需要 | 额外空间 |
|---|---|---|---|
| L1 固件 | Keil 编译 + ST-Link 烧录 | Keil MDK、ST-Link、开发板 | 0 |
| L2 上位机 | PC 端 tkinter 界面（模拟/真实串口） | Python，无硬件可先 `--sim` | ~50 MB |
| L3 视觉 | `new_eye` 双相机 + SAM 分割 | Python + torch + `sam_b.pt` + 两个 USB 摄像头 | ~8 GB |
| L4 大模型 | `Qwen` 本地千问视觉识别 | NVIDIA GPU（推荐）+ Ollama 便携版 + 3.2 GB 模型 | ~20 GB |

只做 L1/L2 不打紧；L3 的 Python 环境复用 `Qwen\.venv`，所以做 L3 时也要走第 6 节的建环境步骤。

磁盘预算：克隆本身约 **15 MB / 853 个文件**；L3 约 +8 GB；L4 再 +20 GB → 建议至少留 **40 GB**。


## 2. 固件层（L1）

### 装工具

| 工具 | 版本/说明 |
|---|---|
| Keil MDK-ARM | **V5.39** |
| ARM 编译器 | **ARMCC V5.06 update 6**（不要换 AC6，工程按 ARMCC5 验证过） |
| Device Family Pack | 工程里写的是 `Keil.STM32F4xx_DFP.3.1.1`，用 Pack Installer 装 |
| ST-Link 驱动 | STSW-LINK009（装完设备管理器里出现 STLink 即可） |
| 芯片 | STM32F407ZGT6 核心板（鹿小班 LXB407ZG-P1） |

### 编译与烧录

1. Keil 打开 `ghr/10.15/Project/STM32F407.uvprojx`，目标名 `STM32F407`；
2. **F7 Rebuild**，应为 0 Error 0 Warning（`Project/Objects/` 不入库，新机必须自己编译）；
3. Options for Target → Debug 选 **ST-Link Debugger**，接口 **SWD**；
4. Utilities → Use Debug Driver，Flash 算法选 **STM32F4xx 1024KB**；
5. **F8** 下载，按复位运行。

上电现象：LED（PC13）闪 1/2/3 次报告串口自检结果 → 舵机停到松开位 180° → 按 PA0 抓夹一步 45° 且全部电机速度模式转 1 秒后停车。

### 这个工程的三个铁律（不知道必踩坑）

1. `MY/main.c` 里的 `*_inline.h` **是模块实现代码，不能删**（删了链接报 `Undefined symbol`）；
   `Drive/Source/gripper.c`、`stepper.c` 是参考副本，**不要加进 Keil 工程**（会 `Multiply defined`）。
2. 按键是 **PA0 内部下拉、按下读到高**，别改成上拉。
3. 源文件 **GBK / UTF-8 混合**，不要批量转码（用 Keil 编辑最安全）。
4. **不要从外部改 `.uvprojx`**——Keil 保存时会用内存里的旧文件列表覆盖它。

`ghr/10.17`（ST7735S 屏测试）、`ghr/10.19`（液晶屏彩色测试）都是**独立工程**，各自打开自己的 `Project/STM32F407.uvprojx`。

## 3. 上位机层（L2）

```powershell
cd ghr\10.15\上位机
run_host.cmd --sim          # 模拟模式，不需要硬件，先把界面跑通（推荐第一步）
```

- 自检：`python -X utf8 -m unittest discover -s tests`（协议/客户端/序列/GUI 共 75 个用例）
- 交互细节（位置模式、一键回 0、`readback_mask` 回读接线）见 `ghr/10.15/上位机/README.md`。

## 4. 视觉层（L3：`new_eye`）

`new_eye` 不单独建环境，**直接用 `Qwen\.venv` 的 Python**，所以先做第 6 节的第 1 步建 venv。

### 4.1 装依赖（选 CPU 或 GPU 一套 torch）

```powershell
cd D:\study\project\robot-competition\Qwen
%LOCALAPPDATA%\Programs\Python\Python312\python.exe -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip

# 有 NVIDIA GPU（RTX 50 系必须 cu128；驱动需支持 CUDA 12.8）
.\.venv\Scripts\python.exe -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu128
# 没有 GPU（能跑，但 SAM 单帧会慢到数秒）
.\.venv\Scripts\python.exe -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cpu

.\.venv\Scripts\python.exe -m pip install -r requirements-camera.txt -r requirements-vision.txt
```

- `requirements-vision.txt` = `ultralytics==8.3.228` + `numpy==2.2.6` + 相机依赖；
- YOLO-World 权重 `yolov8s-worldv2.pt`、CLIP 文字编码器会自动下载到 `Qwen\models\yolo`、`Qwen\cache\clip`；
- 验证：`.\.venv\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available())"`

### 4.2 放 SAM 权重（357.7 MB，**不在仓库里**）

二选一：

```powershell
# ① 从旧电脑直接拷
#    new_eye\models\sam_b.pt  →  新电脑同路径

# ② 自动下载（ultralytics 官方 assets，约 375 MB）
cd D:\study\project\robot-competition\new_eye\models
..\..\Qwen\.venv\Scripts\python.exe -c "from ultralytics import SAM; SAM('sam_b.pt')"
```

缺权重时 `auto_segment.py` 会报 `未找到SAM权重，请把sam_b.pt放入new_eye/models/`。

### 4.3 启动与标定

```powershell
cd D:\study\project\robot-competition
Qwen\.venv\Scripts\python.exe new_eye\gui.py
# 摄像头权限被拒 / 打不开时用管理员方式：
new_eye\run_gui_as_admin.cmd
```

首启先「扫描相机」看索引，然后在 `new_eye\config.json` 里改**这几项是本机专属**的：

| 字段 | 换机后怎么办 |
|---|---|
| `top_camera_index` / `side_camera_index` | 跑 `python new_eye\camera_probe.py` 查实际索引 |
| `top_rotation` / `side_rotation` | 在界面里转正后点"保存配置" |
| `top_points` / `side_points` | 界面里重新四点框选（左上→右上→右下→左下） |
| `empty_background` | **现在是绝对路径** `D:\study\project\robot-competition\new_eye\runtime\empty_background.png`，换机要重新"采集空托盘" |
| `pixels_per_mm` | 按 `new_eye\标定操作手册.md` 重新标 |

验证：打开双画面 → 四点框选 → 「单次识别」→ `new_eye\runtime\latest_targets.json` 里 `targets` 有内容、`motion_authorized` 恒为 `false`。

## 5. 大模型层（L4：`Qwen`，可选）

前置：NVIDIA GPU（RTX 5060 Laptop 实测 8 GB 显存；**RTX 50 系必须 cu128 轮子**）+ 支持 CUDA 12.8 的驱动 + **Python 3.12** + 约 20 GB 磁盘。

```powershell
cd D:\study\project\robot-competition\Qwen
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

`setup.ps1` 会依次：建 `.venv`（若无）→ 下 Ollama 便携版（`download_runtime.py`，v0.40.5，只取所需后端）→ 下 `qwen2.5vl:3b`（`download_model.py`，约 3.2 GB，SHA256 校验）→ 启动服务（只监听 `127.0.0.1:11434`）。

**换机要改的两处硬编码：**

1. `Qwen\setup.ps1` 第 7 行：`$python = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python312\python.exe'` —— Python 装在别处就改这一行；
2. `Qwen\download_cuda.py` 第 23 行：`urllib.request.build_opener(... 'https':'http://127.0.0.1:7897')` —— **写死了代理**，新机没有这个代理就去掉 `ProxyHandler`（或换成自己的代理），否则下 3.27 GB 的 torch 轮子会连不上。

常用命令（都在 `Qwen` 目录下）：

```powershell
.\start.ps1                                                   # 启动服务
.\stop.ps1                                                    # 停止
.\runtime\ollama.exe ps                                       # 看显存/模型
Get-Content .\logs\server.stderr.log -Tail 30                 # 看日志
.\recognize.cmd .\samples\dog-448.jpg --categories 动物 工具 文具 生活用品   # 单图识别
camera_preview.cmd                                            # 相机 + YOLO-World 实时预览（管理员）
```

`camera_preview` 识别结果写到 `Qwen\data\vision_targets.json`，由上位机「视觉目标」页**只读**导入；视觉端不打开串口、不动物理机构。

## 6. 硬件接线（要实物复刻时）

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| 舵机（抓夹） | **PB6** | TIM4_CH1，50 Hz PWM | 500~2500 us ↔ 0~270°，上电停在 180°（松开） |
| 按键 | **PA0** | GPIO 输入，**内部下拉** | 按下读到高电平 |
| 步进电机 | **PA2** | USART2 TX，115200 8N1 | 只发不收；多台靠地址区分 |
| 回读（可选） | **PA3** | USART2 RX，115200 8N1 | 接驱动器 TXD，需二极管线与等处理 |
| 板载 LED | **PC13** | GPIO 输出 | 低电平点亮 |
| 调试串口 | PA9 / PA10 | USART1 | 预留 |

电源：步进驱动器要独立 **12~48 V** 电机电源；舵机 **4.8~7.4 V**；**所有地必须共地**。
电机地址：Z=1、托盘=3、X=4、Y=5。
四路 TXD 不能直接并联到 PA3，方案与风险见 `ghr/10.15/上位机/README.md` 开头（推荐二极管线与；或改 `readback_mask` 只开已接的轴）。

## 8. 换机常见坑

| 症状 | 原因 / 处理 |
|---|---|
| 找不到 `.venv`、`models`、`Objects` | 正常，这些不入库，按上面各节重建 |
| `torch` 导入报不支持的架构 / `sm_120` | RTX 50 系必须装 **cu128** 轮子，别装 cu121/cpu |
| pip 装不上 torch | 网络问题；可改用 `download_cuda.py`（记得改掉写死的代理） |
| `setup.ps1` 说找不到 Python 3.12 | 改脚本里那行路径，或把 Python 装到 `%LOCALAPPDATA%\Programs\Python\Python312` |
| 摄像头打不开 | 关掉占用摄像头的程序；或用管理员方式启动 / `run_gui_as_admin.cmd` |
| 相机索引不对 | `camera_probe.py` 查，改 `config.json` 或界面里重新扫描 |
| 识别结果坐标全错 | 没重新四点框选 / 空托盘背景还是旧路径 |
| Keil 保存后从外部加的 `.c` 不编译 | 已知行为，模块实现走 `*_inline.h`，不要改工程文件 |
| 源文件中文乱码 | 本来就是 GBK/UTF-8 混合，用 Keil 看，别批量转码 |
| `git push` 报 `couldn't create signal pipe` | 受限环境里 Git 自带 ssh 有问题，设 `GIT_SSH_COMMAND=C:/Windows/System32/OpenSSH/ssh.exe` |
| `push` 报 `Failed to connect ... over proxy` | 用的 HTTPS 但代理没开；改 SSH 或开代理 |
| `non-fast-forward` | 先 `git pull --rebase` 再推 |

## 9. 仓库里没有、需要自己带过去的东西

- 私钥（如 `D:\study\git\key\id_ed25519`）——**绝不入库**，用 U 盘/加密盘拷；
- `new_eye\models\sam_b.pt` —— 357.7 MB，可拷也可按 4.2 下载；
- `Qwen\.venv` / `Qwen\models` / `Qwen\runtime` / `Qwen\downloads` / `Qwen\cache` —— 全部可用脚本重建（联网更省事）；
- 本机标定数据（相机索引、四点坐标、`pixels_per_mm`、空托盘背景）—— 换机必须**重新标**；
- 硬件实物（核心板、ST-Link、驱动器、舵机、夹爪、摄像头、电源）。
