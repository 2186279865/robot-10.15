# 样例图

这四张是**真机相机**拍的原始帧（不是截图），用来做离线测试：

| 文件 | 来源 | 内容 |
|---|---|---|
| `real_cam0.jpg` | 旧机（2026-10-23 白天） | 顶视：俯视托盘 + 爪子 + 一个蓝色六棱柱 |
| `real_cam1.jpg` | 旧机 | 侧视/斜视：能看到圆筒与桌面 |
| `real_new0.jpg` | 新机（2026-10-23 夜） | 侧视（被丝杠挡了上半屏） |
| `real_new1.jpg` | 新机 | 正俯视托盘（顶视） |

用法：

```bat
python 04-队友视觉调试包/tools/vision_offline.py --image 04-队友视觉调试包/samples/real_cam1.jpg
```

注意：这些是原图（1280×720），**没有**做真机流水线里的四点单应（700×700），
所以 `center_tray` 的归一化基准和真机不同；只用来验证"能不能出结果、字段对不对"。

换自己的图也没问题，只要是相机原图（BGR 三通道）即可。
